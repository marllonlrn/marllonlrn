## 🍣 Projeto em destaque — Kami Sushi

**Tecnologia para ajudar o negócio da minha família.**

O [Kami Sushi](https://github.com/marllonlrn/Kami-Sushi-Projeto) é uma aplicação web para organizar pedidos, acompanhar o preparo na cozinha, gerenciar mesas e cardápio e consultar o histórico de vendas.

### O que o projeto reúne

- **Pedidos:** registro por canal, itens, quantidades, observações e cálculo do total.
- **Cozinha:** acompanhamento dos pedidos entre recebido, preparando e pronto.
- **Mesas e comandas:** consulta de consumo e fechamento da conta.
- **Cardápio:** cadastro, edição, exclusão e busca de produtos.
- **Vendas e dados:** filtros por período, faturamento, ticket médio e exportação de backup em JSON.
- **Sincronização:** atualização de pedidos e cardápio em tempo real com **Cloud Firestore**.

**Tecnologias:** JavaScript · HTML · CSS · Firebase / Cloud Firestore

O projeto também utiliza **Node.js** para o servidor local e as verificações, além de **GitHub Actions** para executar os checks. A aplicação atual se conecta diretamente ao Firebase; o desenvolvimento de um back-end próprio faz parte dos meus interesses de estudo.
